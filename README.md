# 📊 WhatsApp Chat Analyzer

A powerful and interactive web app to analyze WhatsApp chat data and extract meaningful insights. Whether you're curious about who texts the most, what emojis dominate your group, or how your chat activity trends over time — this tool has got you covered.

![Streamlit App Screenshot](assets/demo_screenshot.png) <!-- Replace with your screenshot path -->

---

## ✨ Features

- ✅ Upload `.txt` chat exports directly from WhatsApp (English format)
- 📅 Activity timeline: daily, weekly, monthly
- 🧍 Individual participant analysis
- 💬 Most common words (after stopword removal)
- 😂 Emoji distribution
- 📈 Beautiful visualizations (bar charts, line graphs, heatmaps)
- 📤 Media/link share count
- 🌍 Web interface built with Streamlit
